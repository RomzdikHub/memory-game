# Code Memory

Code Memory is a memory card game where players need to find matching pairs of programming language logos.

## Features

- 16 cards with 8 matching pairs
- Random card shuffle
- Moves and pairs counters
- New Game functionality
- Win modal
- Leaderboard with top 10 results
- Results saved in localStorage

## How to Play

1. Open two cards.
2. If the cards match, they remain open.
3. If they do not match, they close after a short delay.
4. Find all 8 pairs to win the game.
5. Try to complete the game in as few moves as possible.

## Run Locally

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` using Live Server or another local development server.
